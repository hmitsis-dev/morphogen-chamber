what this is

a fake hedge fund. there is no fund. the prices are real (crypto, via a free public API); everything built on top of them — the "signal", the "conviction", the backtest — is satire.

the actual joke

the confidence number is a live illustration of the Grossman–Stiglitz paradox: if markets were perfectly efficient, no one could profit from gathering information, so no one would bother, so markets couldn't stay efficient. private information has value because it's private — the moment it's public, the edge is gone.

so: confidence here starts high when you're the only visitor, and mathematically decays toward 50% — a coin flip — as more people load this page. it's not a metaphor. it's computed directly from the live viewer count, every two seconds.

the backtest

generated once from a random walk, then smoothed twice. the Sharpe ratio shown is real arithmetic run on that fake series — which is exactly how a backtest ends up absurdly, suspiciously smooth. the math isn't lying. the input is.
